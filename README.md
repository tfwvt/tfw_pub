# tfw_pub

## Website shell

A five-page static site shell (no build step, no dependencies) for an interactive media company.

- `index.html`, `work.html`, `services.html`, `about.html`, `contact.html`
- `css/styles.css` — design tokens, layout, light/dark themes
- `js/main.js` — mobile nav, scroll reveal, work filters, contact form validation

Open `index.html` in a browser, or serve the folder with `python3 -m http.server`.
The company name, copy, projects and contact details are placeholders, and the contact form is not connected to a backend.
